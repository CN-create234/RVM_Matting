# 2D 姿态先验 V1 实验记录

## 目标

在不改变 RVM 原始推理路径的前提下，使用 Sapiens2 的人体关键点，对容易被误判为背景的手、腕和前臂区域施加保守的 Alpha 下界。

## 方法

- 姿态模型：Sapiens2 0.4B Pose，308 个关键点。
- 先验区域：肘—腕胶囊区域，以及高置信度手部关键点的凸包。
- 安全约束：
  - 只允许提高 Alpha，绝不降低 RVM 原始 Alpha；
  - 肘、腕或手部关键点置信度不足时自动跳过；
  - 未提供 `--pose-json` 时，算法行为与原始 RVM 完全一致；
  - Pose JSON 与 Alpha 分辨率不一致时直接报错，避免坐标错位；
  - 模型权重与第三方源码保存在忽略目录，不提交到 Git。

## 首轮实验

- 数据：`Test1228_1_lab` 的 0160–0167，共 8 帧，分辨率 1920×1080。
- 参数：关键点阈值 0.25，目标 Alpha 0.98。
- 输出：`Midterm/PoseFusion_Sapiens2_0160_0167/`（实验图像不提交 Git）。
- 姿态推理耗时：模型加载后约 1.1 秒/帧。

复现实验的两步命令：

```powershell
.\run_sapiens2_pose.ps1 -InputDir <原始PNG目录> -OutputDir <姿态输出目录>

external\.venv-sapiens2-py310\Scripts\python.exe pose_guided_matting.py `
  --alpha-dir <RVMResults目录> `
  --pose-json <姿态输出目录\*_predictions.json> `
  --output-dir <融合输出目录> `
  --save-diagnostics
```

完整管线也可在原有 `Composure.py` 命令后添加 `--pose-json <JSON路径>`；不添加该参数时不启用本功能。

## 初步结论

V1 能在手部缺失案例中补回与人体骨架一致的双手/前臂区域，修改范围约占整帧 0.29%–0.47%，没有改变人体其他区域，也不会侵蚀已有前景。当前结果仍属于“姿态约束的几何修复”，不是最终的精细 Matting：手指边缘可能偏硬，且没有 Ground Truth 时不能仅凭新增面积判断精度提升。

## 下一步验证

1. 使用 UE 输出 Actor/Object Mask 作为 Ground Truth，报告手部 ROI 的 SAD、MSE、IoU、Recall 和整帧误检面积。
2. 在阈值、目标 Alpha、前臂半径和羽化半径上做消融实验。
3. 若几何先验提高 Recall 但降低边缘精度，将姿态区域改为引导局部高分辨率 Matting，而不是直接写入高 Alpha。
4. SSS/皮肤材质因素优先作为 UE 数据增强变量，验证不同 Subsurface 参数下的鲁棒性。
